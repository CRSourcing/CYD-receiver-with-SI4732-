# CYD-receiver-with-SI4732-
A 0.15-30MHz AM/SSB/CW receiver, based on the popular CYD (cheap yellow display). This receiver uses the firmware for SI4732-receivers from my other repo, adapted for the touch controller and GPIO's of the ESP32-2432S028 CYD.The file readmeCYD.txt explains how to wire the SI4732 to the CYD. This project requires soldering and soldering skills. A good soldering iron or hot air should do.
